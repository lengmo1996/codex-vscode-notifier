# 安全报告 / Security reporting

请勿在公开 Issue 中提交令牌、原始会话、完整 Codex Home、凭据、私人服务器信息或尚未公开的漏洞利用细节。

认证绕过、跨用户访问、清理越界等安全问题，请通过仓库 **Security → Advisories → Report a vulnerability** 私下报告，并用合成数据提供最小复现。若该入口不可用，可先创建不含细节的 Issue，请维护者提供私密渠道；不要附带敏感信息。

维护范围为最新发布版本。不承诺固定响应时限；确认修复前，请自行决定是否暂停受影响功能。

Do not put tokens, raw conversations, a complete Codex Home, credentials, private server details, or undisclosed exploit details in public issues.

For authentication bypasses, cross-user access, cleanup boundary failures, or other security issues, use **Security → Advisories → Report a vulnerability** privately. Provide a minimal reproduction with synthetic data. If this entry is unavailable, open an issue without details asking for a private channel; do not attach sensitive files.

The latest release is maintained. No fixed response time is promised. Decide whether to pause affected functionality until a fix is confirmed.

See [PRIVACY.md](PRIVACY.md) for data handling and isolation boundaries.
